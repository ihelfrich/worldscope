## United States Politics and Policy

The **Federal Communications Commission** published a [Second Report and Order](https://www.federalregister.gov/documents/2026/07/27/2026-15123/review-of-submarine-cable-landing-license-rules-and-procedures-to-assess-evolving-national-security) finalizing a new licensing regime for submarine cable landing equipment (SLTE). The rule creates a blanket license for current operators meeting national-security conditions and establishes a new certification pathway for future SLTE owners. This is the regulatory answer to years of Congressional concern about Chinese-manufactured equipment in undersea cables; the Order effectively codifies the informal review process the Executive Branch has been running through the [Team Telecom](https://www.justice.gov/nsd/national-security-division-faq-team-telecom) interagency process since 2020. The simultaneous [Second FNPRM](https://www.federalregister.gov/documents/2026/07/27/2026-15120/review-of-submarine-cable-landing-license-rules-and-procedures-to-assess-evolving-national-security) solicits comments on whether to extend the regime further.

## Cyber and Biosecurity

**FIRST-OF-KIND KEV CALLOUT**: CISA added [CVE-2026-0770](https://nvd.nist.gov/vuln/detail/CVE-2026-0770) to the Known Exploited Vulnerabilities catalog on July 21, marking the first AI agent-framework application ever catalogued in the KEV database. The vulnerability affects **Langflow** (vendor: Langflow, product: Langflow), an open-source visual programming framework for building AI agents and LLM workflows. The vulnerability type is "Inclusion of Functionality from Untrusted Control Sphere," a class of flaw that allows malicious code to be executed within an AI workflow via untrusted external component loading. The structural signal: as AI agent platforms become enterprise infrastructure, they inherit the attack surface of traditional application servers. The first KEV entry for an LLM orchestration framework is a policy-relevant milestone; expect CISA to follow with guidance on agent framework hardening.
