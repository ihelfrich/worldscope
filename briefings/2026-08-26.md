Watch for Senate Foreign Relations and House Foreign Affairs committee hearings in September.

First launch is targeted for 2029. SpaceX President Gwynne Shotwell cited AI satellite constellation demand as the primary driver. The [National Space Transportation Policy](https://www.federalregister.gov/documents/2026/08/25/2026-17372/the-national-space-transportation-policy) published simultaneously in the Federal Register is not coincidence: it streamlines federal airspace and environmental review for commercial launch sites, removing barriers that the Starbase Texas permitting process encountered.

## Cyber and biosecurity

**MLflow CVE-2026-64849 (CVSS 9.3): FIRST-OF-KIND KEV CALLOUT.** This is the first vulnerability in an AI/ML workflow management platform to appear in CISA's Known Exploited Vulnerabilities catalog. MLflow is the dominant open-source platform for tracking experiments, packaging code, and deploying machine learning models — it runs in AI development environments across government, defense contractors, and commercial cloud. The structural signal: as AI/ML development platforms become standard infrastructure (like web servers were in 2010), their attack surface becomes a high-value target for credential harvesting and lateral movement. CISA added [CVE-2026-64849](https://securityaffairs.com/197558/hacking/u-s-cisa-adds-a-mlflow-flaw-to-its-known-exploited-vulnerabilities-catalog.html) on August 19; the SSRF flaw allows an unauthenticated attacker to reach cloud metadata endpoints (AWS IMDS, GCP metadata server, Azure IMDS) via the webhook test endpoint, exfiltrating temporary cloud credentials. Federal patch deadline: September 2, 2026. Any organization running MLflow 3.14.x or earlier in an internet-exposed configuration is at active exploitation risk.

**Gitea CVE-2026-60004 (CVSS 9.8)** is a remote code execution vulnerability that allows a user with write access to a Gitea repository — which can be obtained by self-registration on a default-configuration public instance — to [execute arbitrary shell commands](https://thehackernews.com/2026/08/critical-gitea-rce-actively-exploited.html) as the Gitea service account. This is effectively unauthenticated RCE in practice. CISA added it to KEV August 25 with a federal patch deadline of August 28 — an unusually short window reflecting active exploitation. The payload in reported attacks is a miner-like executable, but RCE gives an attacker arbitrary code execution capability. Gitea hosts government, academic, and corporate source code repositories globally; self-hosted instances are often less carefully patched than cloud-hosted alternatives. Federal agencies and defense contractors using self-hosted Gitea should treat this as P0.
