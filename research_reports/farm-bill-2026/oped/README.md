# Securitas — the op-ed

An essay drawn from the full-text analysis of **H.R. 7567**, the *Farm, Food, and
National Security Act of 2026* — the engrossed (House-passed) text, passed
224–200 on **30 April 2026**, not yet taken up by the Senate.

| File | What it is |
|---|---|
| [`securitas.html`](securitas.html) | The **online blog post** — self-contained, responsive, styled. Open in a browser / serve via GitHub Pages. |
| [`securitas.typ`](securitas.typ) | The **Typst** source for the print/PDF edition (magazine layout: hero, drop cap, pull quotes, embedded figures, running footer). |
| [`securitas.pdf`](securitas.pdf) | Compiled PDF of the Typst article. |
| [`linkedin.md`](linkedin.md) | A short **LinkedIn** post to introduce the piece. |
| [`assets/hero.png`](assets/hero.png), `assets/coin.png` | Original editorial artwork (drawn here; no third-party images). |

Charts embedded in the piece come from [`../figures/`](../figures/) and are
generated by `tools/build_farmbill_figures.py` (the provision-count charts are
tallied directly from the section-by-section notes).

## Rebuild

```bash
pip install matplotlib typst              # typst = the Python binding (bundles the compiler)
python tools/build_oped_assets.py         # -> oped/assets/hero.png, coin.png
python tools/build_farmbill_figures.py    # -> figures/*.png
# compile the Typst article to PDF (root must include ../figures):
python -c "import typst; typst.compile('research_reports/farm-bill-2026/oped/securitas.typ', \
  output='research_reports/farm-bill-2026/oped/securitas.pdf', \
  root='research_reports/farm-bill-2026')"
```

*The essay is opinion and analysis. Every factual claim traces to a cited
section in the [notes](../notes/); see the endnote in the piece.*
